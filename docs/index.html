The proposed set layer is cosmetic: every pack keeps the same complete card pool and the same default 1% foil roll per card. The regional map is a subdued monochrome impression in the dark foil stock, while an actual in-game landmark scene sits behind the item inside the artwork frame. Both images stay fixed while the light and foil sheen move above them. RuneLite can reproduce the stack with cached PNGs, AlphaComposite, and the existing Java2D card pipeline. Treatment weights always total 100% after a foil is rolled. The existing 1-in-3,000 Apex event keeps its top-tier, 5× foil, and guaranteed-foil rules; each Apex foil then uses the selected set’s same treatment table.
